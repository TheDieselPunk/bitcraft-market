How the verdict works
Good deal under 85% of fair value
Fair 85–115% of fair value
Overpriced over 115% of fair value

Fair value is the expected ingredient cost of rolling that tier and quality yourself: craft at T1, upgrade tier by tier, and stop (selling the tool, if leftovers are credited) whenever a roll makes continuing cost more than it's worth. It uses the same upgrade odds as Tool Rolling.

It's an average. Rolling can cost much more if you're unlucky, while a listing is a fixed price.
